# ⚽ Atlas FC

Atlas FC est un projet web qui permet de gérer un effectif de football et de préparer une composition d'équipe en 4-4-2.

Ce projet me permet de mettre en pratique mes connaissances en **JavaScript** et en **Tailwind CSS**, notamment la manipulation du DOM, les événements, la validation des formulaires et le stockage des données avec `localStorage`.

## 🛠️ Technologies

- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- LocalStorage
- Git & GitHub

## ✨ Fonctionnalités

- Ajouter des joueurs (nom, poste et numéro).
- Valider les champs du formulaire et afficher les erreurs.
- Afficher les joueurs dynamiquement.
- Compter le nombre de joueurs.
- Sauvegarder les données dans le navigateur.
- Personnaliser l'interface avec Tailwind CSS.
